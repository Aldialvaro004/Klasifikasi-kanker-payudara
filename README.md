# Klasifikasi-kanker-payudara
  Notebook ini digunakan untuk menganalisis dan mengklasifikasikan data kanker payudara. Setelah pembersihan dan normalisasi data, model klasifikasi Logistic Regression diterapkan untuk memprediksi apakah kanker bersifat ganas  atau jinak , dilengkapi evaluasi akurasi dan confusion matrix.
